images/fleet/sedan/01.webp ... 12.webp
images/fleet/minibus/01.webp ... 12.webp
images/fleet/mercE/01.webp ... 12.webp
images/fleet/mercV/01.webp ... 12.webp

Recommended order:
01 front exterior
02 side exterior
03 rear exterior
04 front interior
05 rear seats
06 seats and passenger space
07 dashboard
08 luggage space
09 side doors / entrance
10 child seat
11 vehicle detail
12 night / evening view

Recommended export:
- WebP
- landscape 1600 x 1000 px (or similar 16:10 / 3:2 ratio)
- 200-500 KB per image
- remove or blur all license plates before upload
- do not use customer faces without written permission

The website currently uses a temporary stock fallback for slots 01 and 04.
All other missing files show an explicit upload placeholder instead of repeating a photo.
