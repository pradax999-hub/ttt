🪝 Stripe Webhook — налаштування

Робиться один раз після деплою сайту на домен. Весь час займає ~5 хвилин. Навіть без вебхука оплата працює (сервер сам запитує статус у Stripe), але вебхук робить підтвердження миттєвим і надійним.

1 Скопіюйте URL вебхука

Це адреса вашого запущеного сервера — підставте її у Stripe:

…

2 Додайте endpoint у Stripe

  • Відкрийте dashboard.stripe.com → Developers → Webhooks
  • Кнопка Add endpoint
  • URL: вставте адресу з кроку 1
  • Events: checkout.session.completed та checkout.session.async_payment_succeeded
  • Натисніть Connect

3 Збережіть signing secret

Після створення endpoint відкрийте його → Signing secret → скопіюйте і вставте у .env:

STRIPE_WEBHOOK_SECRET=whsec_...

Після зміни .env перезавантажте сервер (pm2 restart all або node server.js).

4 Протестуйте

  • У Stripe на сторінці endpoint натисніть Send test event — серwer має відповісти 200
  • Зробіть тестову оплату з сайту картою 4242 4242 4242 4242
  • Статус замовлення зміниться на «Оплачено», клієнту прийде email
Якщо Stripe показує помилку — перевірте: (1) сайт доступний по HTTPS з зовнішнього інтернету, (2) firewall прокидає порт, (3) STRIPE_WEBHOOK_SECRET скопійований без пробілів.
